# Description

**Problem:** 上班时间长且枯燥，用户希望在工作的间隙偶尔被一条有意思的内容「惊喜」一下，带来短暂的放松与愉悦。

**Audience:** 使用 Windows 桌面办公的上班族（当前为本人）。

**Expected outcome:** 一个常驻后台的桌面小工具，在工作时段内以随机间隔、以不打扰的方式弹出单条趣味内容卡片（冷笑话、脑筋急转弯、冷知识、趣闻/新闻）；用户可一眼看完即关闭，也可继续看下一条或收藏，从而在枯燥的工作中获得轻量的「小惊喜」。

# Acceptance Criteria

- [ ] 程序启动后常驻系统托盘，任务栏不出现常驻窗口
- [ ] 在工作时段内按随机间隔（默认 40~90 分钟，可配置）自动弹出内容卡片
- [ ] 弹出的卡片不抢占键盘焦点、不阻塞用户当前操作
- [ ] 卡片在若干秒后自动消失，无需用户操作
- [ ] 卡片提供「再来一个」「收藏」「安静一会」三个操作
- [ ] 内容类型至少覆盖：冷笑话、脑筋急转弯（先题后答案，可点击揭示）、冷知识、趣闻/新闻
- [ ] 检测到全屏应用/演示/会议场景时，自动推迟或不弹出
- [ ] 短时间内不重复推送同一条内容
- [ ] 无网络时仍可从本地内容库正常推送
- [ ] 有网络时能抓取外部来源的趣闻/新闻，无网络时自动降级到本地内容库
- [ ] 被收藏的内容可再次查看

# Notes

**Constraints**
- 目标平台：Windows 桌面；实现语言：Python
- 联网内容源需考虑稳定性与合规性，本地内容库需便于扩充
- 弹窗须以「不打扰」优先：不抢焦点、不遮关键区域、可一键暂停

**Open Questions**
- 工作时段的具体起止时间与随机间隔，是否需要用户可配置？
- 联网新闻/趣闻选取哪些来源？
- 是否需要「今日乐子」汇总视图？
- 偏好学习（喜欢的类型多推）是否纳入首版？

**Out of Scope**
- 账号系统、社交分享平台
- 移动端
- 海量内容库
