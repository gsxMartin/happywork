# Summary

一个常驻系统托盘的后台桌面小工具，在工作时段内以随机间隔弹出单条趣味内容卡片（冷笑话、脑筋急转弯、冷知识、趣闻/新闻），以「不打扰、一眼看完」为原则，为用户枯燥的上班时光带来轻量的「小惊喜」。

# Key Decisions

以下为需求确认阶段与用户澄清后确定的关键决策（WHAT 层面）：

1. **内容来源：本地 + 联网并重**
   - 本地精选库保证离线可用与质量下限；联网抓取提供更鲜活的趣闻/新闻。
   - 无网络时自动降级为纯本地推送。

2. **首版范围：标准**
   - 卡片操作包含「再来一个」「收藏」「安静一会」。
   - 收藏内容可再次查看。
   - 首版**不含**偏好学习（越爱看越推）与「今日乐子」汇总视图。

3. **工作时段与间隔（默认，可配置）**
   - 默认工作时段：工作日 9:30–18:30。
   - 默认推送间隔：40~90 分钟随机。
   - 提供一个简单设置入口可修改以上参数。

4. **不打扰原则**
   - 卡片不抢键盘焦点；全屏/演示/会议场景自动推迟或不弹出。
   - 卡片自动消失；提供「安静一会」（暂停一小时）。
   - 短时间内不重复推送同一条内容。
